# 001. Generic, self-hosted, open source

Status: accepted
Date: 2026-10-19

## Context

Sym started as one person's work bot. A bot shaped around one company helps nobody else and collects private assumptions in its code.

## Decision

Sym is a generic, self-hosted, open-source Slack agent. The repository names no company, team, customer, or private repository. Adopter specifics live in a pack (decision 010).

## Consequences

Every feature must make sense for an unknown adopter. Examples and mockups use invented names. Company-specific playbooks never land here.
